개인정보처리방침

시행일: 2026년 8월 27일 · 최종 업데이트: 2026년 8월 27일

IRL Dashboard는 개발자 본인의 YouTube 라이브 방송을 관리하기 위한 개인용 도구이며, 불특정 다수의 회원 가입이나 계정 생성을 제공하지 않습니다.

1. 처리하는 정보

운영자가 Google OAuth에 동의하면 앱은 기능 수행에 필요한 범위에서 다음 정보를 처리할 수 있습니다.

  • OAuth 액세스 토큰과 갱신 토큰
  • YouTube 채널, 영상, 활성 라이브 방송 및 라이브 채팅 식별정보
  • 현재 라이브 채팅 메시지와 작성자 채널 식별정보
  • 운영자가 선택하여 적용하는 라이브 방송 썸네일 이미지

2. 이용 목적

  • 현재 활성 YouTube 라이브 방송 확인
  • 운영자가 선택한 라이브 썸네일 적용
  • 라이브 채팅 조회 및 운영자 요청에 따른 메시지 전송
  • 운영자 요청에 따른 라이브 채팅 사용자 관리
  • OAuth 액세스 토큰의 자동 갱신

3. 저장과 보관

OAuth 자격정보와 방송 운영 데이터는 운영자가 관리하는 로컬 IRL 서버에 저장됩니다. 공개 GitHub Pages에는 OAuth 토큰, Firebase 인증정보 또는 비공개 방송 데이터를 저장하지 않습니다. 토큰은 운영자가 교체·삭제하거나 Google 계정에서 앱 권한을 취소할 때까지 보관될 수 있으며, 로컬 채팅 기록과 썸네일은 운영자가 직접 삭제할 수 있습니다.

4. 제3자 서비스

기능 제공을 위해 Google YouTube Data API를 사용합니다. 공개 오버레이 제공에는 GitHub Pages가 사용될 수 있으며, 장비 상태 동기화에는 별도로 구성된 Firebase Realtime Database가 사용될 수 있습니다. 각 서비스에는 해당 사업자의 개인정보처리방침이 적용됩니다.

5. 정보의 공유 및 판매

처리한 Google 사용자 데이터를 광고 목적으로 사용하거나 판매하지 않습니다. 법령상 의무가 있거나 운영자가 명시적으로 요청한 기능 수행에 필요한 경우를 제외하고 제3자에게 제공하지 않습니다.

6. Google API 데이터 정책 준수

IRL Dashboard의 Google API 사용자 데이터 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다.

7. 보안

OAuth 토큰은 공개 소스 코드에 포함하지 않고 운영자의 로컬 설정 저장소에서 관리합니다. 관련 제어 API는 패널 인증으로 보호하며, 기능 수행에 필요한 최소한의 권한만 요청합니다.

8. 삭제 및 권한 철회

운영자는 IRL Dashboard 설정에서 OAuth 자격정보를 삭제하고 로컬 기록을 제거할 수 있습니다. 또한 Google 계정의 서드 파티 연결 관리에서 앱의 YouTube 접근 권한을 언제든지 취소할 수 있습니다.

9. 아동의 개인정보

이 앱은 아동을 대상으로 제공되지 않으며 아동의 개인정보를 의도적으로 수집하지 않습니다.

10. 방침 변경 및 문의

기능이나 관련 법령의 변경에 따라 본 방침이 수정될 수 있으며, 변경 시 이 페이지의 최종 업데이트 날짜를 갱신합니다. 문의는 GitHub Issues를 이용해 주세요.
